# Tajikistan Monitor Clean

Самостоятельный full-stack каркас национального информационного монитора. Старый черновик и исходный World Monitor не изменяются.

## Что уже работает

- интерактивная карта с границами 5 регионов, 47 районов и 78 населёнными пунктами;
- геопривязка новостей по RU/TJ и историческим названиям с confidence и фрагментом-доказательством;
- группировка маркеров новостей и синхронная фильтрация карты и ленты по региону/району;
- адаптивная панель в стиле intelligence dashboard;
- backend-агрегатор RSS с кешем, таймаутами и статусами источников;
- отдельные HTML-адаптеры КЧС, Meteo и НБТ с retry, лимитом ответа и состоянием `degraded` при изменении разметки;
- поиск, категории, тревожные статусы и карточки новостей;
- API: `/api/health`, `/api/news`, `/api/status`, `/api/weather`, `/api/exchange-rates`, `/api/ai/explain`;
- AI-объяснение с безопасным демонстрационным режимом без ключа.

## Запуск

```powershell
npm install
npm run dev
```

Frontend: `http://127.0.0.1:5173`  
Backend: `http://127.0.0.1:8787`

Для AI скопируйте `.env.example` в `.env` и заполните серверные переменные. Ключ никогда не должен попадать во frontend.

AI-разрешение неоднозначной геопривязки отключено по умолчанию. Оно включается только через `GEOLOCATION_AI_ENABLED=true`: тогда заголовок, описание и ограниченный список кандидатов отправляются настроенному `OPENAI_BASE_URL`. Модель не может вернуть `location_id`, которого нет среди кандидатов; сомнительные ответы не создают маркер.

## Сознательно не включено

Реклама, авторизация, Premium/оплата, глобальная геополитика, биржи, авиация, морской транспорт, Tauri, Telegram и лишние варианты приложения.
